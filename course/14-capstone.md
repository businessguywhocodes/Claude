# Module 14: Capstone, Your 30-Day Plan, and Cheat Sheet

**~15 minutes, then 30 days of practice**

## Capstone project

Pick **one real workflow** from your work or personal life that you do at least weekly and that takes you 30+ minutes. Then:

1. **Describe it.** Write down the steps you take today, the inputs, and what the output looks like.
2. **Prompt it.** Do the workflow once with Claude using the briefing template (Module 3).
3. **Package it.** Create a **Project** (Module 6) with instructions and reference files, or a **Skill** (Module 11) for the method.
4. **Connect it.** If it needs data from your tools, add the relevant **connectors**.
5. **Delegate it.** If it has many steps, try it as an **agent** task in Cowork or Claude Code (Module 12).
6. **Measure it.** Note time before vs. after, and the quality difference.
7. **Share it.** Show a friend or colleague what you built and the prompt you used.

Example capstones:
- **Ops:** weekly guest-feedback digest from review exports, with themes and fixes
- **Sales:** pre-call research brief for every new lead
- **Marketing:** monthly content calendar plus first drafts in brand voice
- **Founder:** monthly investor update from metrics and notes
- **Personal:** family trip planner Project, or a monthly budget review from bank exports

## The 30-day plan

**Week 1: Habit**
- Use Claude for at least one real task every day.
- Set profile preferences. Install the mobile and desktop apps.
- Use the "ask me questions first" trick at least 3 times.

**Week 2: Depth**
- Create 1 work Project and 1 personal Project.
- Upload and analyse a real document and a real spreadsheet.
- Build one Artifact you actually use (a checklist, calculator, or tracker).
- Run one Research query on a real decision.

**Week 3: Connect**
- Connect your calendar and email (or other daily tools).
- Create one Skill for a task you repeat weekly.
- Try advanced prompting: tags, quotes-first, or a prompt chain.

**Week 4: Delegate**
- Hand one multi-step task to an agent (Cowork, Claude Code, or Claude in Chrome) using the delegation checklist.
- Finish your capstone.
- Review your wins note: where does Claude save you the most? Double down there.

## One-page cheat sheet

**The briefing formula**
> Context → Task → Audience → What good looks like → Constraints → Materials → "Ask me questions first."

**Power phrases**
- "Before you start, ask me any questions you need."
- "Give me 5 options, from safe to bold."
- "Critique this as [specific person]. Be direct."
- "What's the strongest argument against this?"
- "Based only on the attached document... Quote the relevant parts."
- "If you're not sure, say so."
- "Make it half as long without losing any decision or number."
- "Explain it like I'm smart but new to this, then quiz me."
- "Summarise what we've decided so far" (then start a fresh chat).

**Which feature when**

| Need | Use |
|---|---|
| Quick question or draft | Chat |
| Something reusable or interactive | Artifact |
| A real Word, Excel, PowerPoint, or PDF file | File creation |
| Standing context for a topic | Project |
| Remember me across chats | Memory and profile preferences |
| Sound like me | Custom style |
| Current facts | Web search |
| Deep, multi-source answer | Research |
| Data from my tools | Connectors |
| A repeatable method | Skill |
| A multi-step job done for me | Cowork / Claude Code / Claude in Chrome |
| Automation inside our product | API |

**Safety checklist**
- Right account (work vs. personal)
- No secrets, minimal personal data
- Verify facts, numbers, and citations
- Experts for health, legal, tax, and finance decisions
- Review before agents send, delete, pay, or publish
